# v0.3.1 — Release Readiness

**Release:** v0.3.1 — Learning Session Orchestration  
**State:** Release candidate — final CI validation required

## Architecture

- No `services/learning-session-engine` module is introduced.
- No `com.aigora.learningsession` or `...tutororchestrator.learningsession` package root is introduced.
- Learning Session functionality is implemented in the existing Tutor Orchestrator package/layer structure.
- ADR-008 ownership separation is preserved logically: session mutation and pedagogical decision-making remain distinct responsibilities.

## Mandatory release-plan coverage

- Learning Session identity and lifecycle model: implemented.
- Aggregate invariants and terminal-state protection: implemented.
- Exercise attempt completion: implemented.
- Command/result contracts: implemented.
- Repository, event, trace, telemetry, assessment and Tutor Orchestrator ports: implemented.
- Start session, complete exercise and process progress use cases: implemented.
- Existing deterministic Tutor Orchestrator pipeline integration: implemented in-process.
- In-memory repository and publication/trace/telemetry adapters: implemented.
- Idempotency, expected-version concurrency checks and stale assessment/decision validation: implemented.
- Recovery-state inspection: implemented.
- Decision trace integration: implemented.
- Unit/contract/integration/end-to-end source coverage: included.

## Validation performed in the generation environment

- Java 21 production sources compile successfully with `javac --release 21`.
- Java test sources compile successfully against lightweight JUnit API stubs, validating imports, signatures and constructor wiring.
- Cross-flow smoke execution completed successfully:
  - session starts;
  - exercise completes;
  - assessment is accepted;
  - deterministic Tutor Orchestrator selects `n2`;
  - session returns to `ACTIVE`;
  - four session events are emitted;
  - one session decision trace is recorded.

## Final gate before tag/release

Run in the real repository/CI environment:

```bash
cd services/tutor-orchestrator
mvn clean test
```

The release tag must not be created until the real Maven suite is green. The in-memory adapters prove v0.3.1 semantics only; they do not claim process durability, which is explicitly future scope in the release plan.
