## Overview

The v0.3.1 issues refer to each other by planning task number ("Task 08").
This document maps every task to its GitHub issue and records the dependency
graph in issue numbers, following the
[Traceability Model](../06-engineering/governance/traceability-model.md).

**Single source of truth.** The edges below are mirrored as GitHub
*blocked by* relationships, and all tasks are sub-issues of #253.

**Edge reconciliation.** In 12 tasks the `Depends on` and `Blocks` lists in
the issue bodies did not mirror each other. Every declared edge points from a
lower to a higher task number, so the canonical graph is the union of both
lists (122 edges), and it is acyclic.
